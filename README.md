# 智能视光软件 · 多模态智能体系统

> **参赛赛道**：华北五省（市、自治区）大学生计算机应用大赛 · 大模型与 Agent 赛道
> **作品形态**：基于多模态大模型 + RAG 知识库的智能视光软件（桌面端 / 移动端）
> **参考资料**：《机器人在视光行业中的应用与发展》（尹燕凯，天津工业大学软件学院 · 南开视光论坛新质创研大会）

---

## 一、项目定位

围绕"视光中心日常服务"这一垂直场景，构建一个集 **智能互动问答 · 视光专业知识科普 · 关键技术展示** 三位一体的多模态智能软件。本项目把大模型、Agent、RAG 与 PPT 中提到的深度学习视觉技术作为**可解释的能力背书**，让用户既能"用起来"，也能"看懂为什么"。

### 三大模块（对应比赛作品三部分）

| 模块 | 名称 | 解决什么问题 | 核心能力 |
| --- | --- | --- | --- |
| ① | **智能互动问答** | 患者进店后高频问题无人解答 | RAG 高级检索 + 多模态 LLM + 视光专用 Agent |
| ② | **相关技术展示** | 让大众理解"这个软件为什么聪明" | 深度学习模型可视化 · PPT 中技术的复现 Demo |
| ③ | **科普内容** | 视光知识碎片化、不专业 | 知识库 + 图文科普卡片 + 互动测验 |

## 二、从 PPT 中可借鉴的深度学习技术梳理

把原 PPT 里的"硬核深度学习"按**是否适合做大模型/Agent 赛道的可展示模块**整理成下面这张表，并标出复用建议。

### 2.1 第一部分：视觉感知深度学习（计算机视觉）

| # | PPT 中的技术 | 用 1 句话说清楚 | 我们项目中怎么用 |
| --- | --- | --- | --- |
| 1 | **U-Net / DeepLabv3+（语义分割）** | 给每个像素打一个语义标签的编解码网络 | 封装为 `segment_image` 工具，供 Agent 分割眼底结构 |
| 2 | **SLIC 超像素** | 把相似像素聚成"小方块"，把像素级任务转化为区域级任务 | 作为 `superpixel` 工具的传统算法基线，对比深度学习效果 |
| 3 | **SFCN（深度超像素生成网络）** | 用全卷积网络学习像素到超像素的亲和关系 Q | 作为 `superpixel` 工具的深度升级版 |
| 4 | **LSTM 超像素聚类** | 用循环神经网络保持局部一致性 | 内嵌到超像素工具的后处理链路 |
| 5 | **亲和矩阵 Q + Q-Weighted Soft Aggregation** | 软分配：每个像素按概率归属多个超像素 | 作为分割工具的软分配策略，提升边界精度 |
| 6 | **LSPG-Net（CNN + GNN 融合分割架构）** | CNN 提细节，GNN 抓区域上下文 | **核心工具**：作为 `segment_image` 的骨干网络 |
| 7 | **GraphSAGE / TAGCN / Graph U-Net** | 三种图神经网络，分别擅长归纳学习 / 多项式滤波 / U 形跳跃连接 | 作为分割工具可切换的 GNN 算子 |
| 8 | **FiLM（Feature-wise Linear Modulation）门控融合** | 用一个特征动态调节另一个特征的缩放与平移 | 作为多模态特征融合工具的内部机制 |
| 9 | **多因素超像素嵌入（appearance + position + geometry）** | 把外观、几何、位置三种信息分别编码再融合 | 作为分割工具的特征编码模块 |
| 10 | **Seed-centered Affinity Reassembly** | 以超像素种子为中心重组亲和图 | 作为分割工具的后处理模块 |

### 2.2 第二部分：目标检测与多模态融合（计算机视觉）

| # | PPT 中的技术 | 用 1 句话说清楚 | 我们项目中怎么用 |
| --- | --- | --- | --- |
| 11 | **YOLO 目标检测** | 一阶段实时检测器，单图多目标 + 类别 + 置信度 | 封装为 `detect_object` 工具，供 Agent 检测可疑区域 |
| 12 | **ATMS（自适应三模态评分）** | 综合置信度+空间位置+局部相关性修正标签冲突 | 作为检测工具的多模态评分后处理，提升精度 |
| 13 | **DPL（数据驱动概率化标注）** | 在三维点云上做概率传播，补全低置信度目标 | 作为检测工具的漏检补救策略 |

### 2.3 图像识别 → 封装为 Agent 工具插件（关键设计）

把上面所有视觉模型统一封装成**可被 Agent 调用的工具插件（tools）**，遵循 OpenAI Function Calling / MCP（Model Context Protocol）规范，让大模型在对话中按需自动调用图像识别能力。

| 工具名 | 底层模型 | 功能 | Agent 调用场景示例 |
| --- | --- | --- | --- |
| `segment_image` | LSPG-Net / DeepLabv3+ / U-Net | 对眼底图做像素级语义分割，返回分割掩膜 | 用户上传眼底照："帮我把视盘和血管标出来" |
| `detect_object` | YOLO / RT-DETR | 检测图像中的目标 + 类别 + 置信度 + 框 | "看看这张图里有没有可疑病灶" |
| `ocr_prescription` | PaddleOCR / Qwen-VL | 识别验光单 / 处方单上的屈光度、瞳距等参数 | "帮我读一下这张验光单" |
| `superpixel` | SLIC / SFCN | 生成超像素并返回亲和图 | "把这张图按区域分块看看" |
| `visualize_feature` | 任意骨干网络 | 输出 feature map / attention 热力图 | "解释一下模型是怎么看这张图的" |

**工具插件的价值**：
- 图像识别不再是"独立的技术展示页"，而是**智能问答 Agent 的感知器官**——用户自然语言提问，Agent 自动决定是否调用、调用哪个视觉工具。
- 工具通过标准接口（Function Calling / MCP）暴露，模型、框架解耦，可插拔、可扩展。
- 呼应"大模型 + Agent"赛道主题：**大模型负责理解与决策，视觉工具负责感知与执行**。

## 三、我们项目的创新点（新在哪里）

### 创新 1：图像识别封装为可插拔的工具插件（**核心创新**）

- 把 LSPG-Net、YOLO 等论文级视觉模型统一封装为 **Agent 工具插件**（Function Calling / MCP 规范），大模型在对话中**按需自动调用**，实现"语言理解 + 视觉感知"的真正融合。
- 工具化之后，模型、框架、能力三者解耦，可插拔、可替换、可扩展——后续新增"裂隙灯图像分析""角膜地形图解读"等工具只需挂载新插件。
- 同时保留**可视化**：用户点击结构图节点，可看到 feature map、attention map、热力图，让深度学习"可解释"。

### 创新 2：RAG 高级检索 + 视光专用 Agent 工具调用

- **不止"塞知识"**：构建多路召回（向量 + BM25 + 知识图谱）+ Re-rank + 上下文压缩的 RAG 流水线。
- **Agent 工具调用**：
  - `segment_image` / `detect_object` / `ocr_prescription` / `superpixel`：图像识别工具插件
  - `exam_lookup`：根据症状描述反查可能的视光检查项
  - `pharmacy_guide`：用药/用镜指导
  - `appointment`：挂号/预约接口

### 创新 3：多模态输入 + 多模态输出

- 输入：文字、语音、图片（眼底照片 / 眼镜处方单 / 验光单 OCR）、视频（眼动视频）。
- 输出：文字回答、语音播报、可视化图示（标注出图像中"可疑区域"）、交互式问诊卡片。

### 创新 4：可成长 / 可演化的"生态化"叙事

- 呼应 PPT 第三部分"集群互联、协作生态"，设计多 Agent 协作：
  - `TriageAgent`（分诊）
  - `EducationAgent`（科普）
  - `VisionAgent`（图像解读，调度图像识别工具插件）
  - `ManagerAgent`（任务调度）
- 通过 A2A（Agent-to-Agent）协议互相调用，模拟"集群协作生态"。

## 六、核心功能 Demo 规划

### Demo 1：智能问答（端到端）
1. 用户语音："我家孩子最近老眯眼看东西，是近视了吗？"
2. ASR → Manager Agent → TriageAgent → 调用 RAG（多路召回）→ 检索出"儿童近视筛查指南"+"屈光不正检查流程"
3. 回复："根据描述，怀疑可能是近视，建议做以下检查……" + 推送科普卡片"如何判断孩子近视"
4. 用户上传眼底照片 → VisionAgent 自动调用 `segment_image` / `detect_object` 工具插件 → 在原图上标注

### Demo 2：图像识别工具插件的自动调用（让人"看懂"）
- 用户上传一张眼底图，只说一句"帮我看看哪里有问题"，Agent 自动完成：调用 `detect_object` 检测可疑区域 → 调用 `segment_image` 分割病灶边界 → 调用 `visualize_feature` 展示模型关注的热力图 → 用自然语言解释结果
- 互动页面：拖动滑块看不同网络（U-Net vs DeepLabv3+）的 feature map 热力图

### Demo 3：科普卡片 + 互动测验
- 卡片化呈现：高度近视并发症、青光眼自查、OK 镜使用须知、视疲劳缓解
- 答对奖励互动表情
