# gcmw 项目文档

本项目文档按 V2.3 实施计划管理，用于承载架构决策、接口、验收、安全、医疗治理和运维记录。

## 目录

- `adr/`：架构决策记录
- `architecture/`：系统架构文档
- `api/`：接口与协议文档
- `acceptance/`：验收记录与基线
- `security/`：安全设计、威胁模型、扫描与审计记录
- `medical-governance/`：医疗内容审核、来源与版本治理
- `operations/`：部署、运维、监控与故障处理

## 规则

- 所有正式文档必须标注版本、日期、负责人和状态。
- 涉及架构、模型、安全、数据、医疗范围的变更应先记录到对应目录。
- 验收证据不能只写结论，必须包含可复核命令、版本和数据。

## 审批入口

- 变更通过 GitHub PR 提交。
- 由相关 Owner（技术/安全/临床/法务/运维）进行 Review。
- 审批通过并合并后，相关文档版本才生效。
