运行环境：Ubuntu，python3
*****************************使用说明*******************************************************************
一、运行python脚本
python base.py
二、交互说明
注：代码里面内置唤醒事件的串口解析代码
【按键1】：固件版本查询
【按键2】：麦克风阵列类型切换（再次键盘输入0设置为线性六麦，1为环形六麦）
【按键3】：设置拾音波束（即手动唤醒，可设置0-5波束）
【按键4】：唤醒词设置（修改awake_word_set字段里面的唤醒词即可自定义，设置后需要等待M2设备重启）
【按键5】：获取降噪音频与原始音频（需要先设置拾音波束，再进行此步骤，默认获取5s音频数据）
**********************************************************************************************************

注意：需要保证已安装有adb环境，程序默认串口已别名为wheeltec_mic
查询adb环境指令：adb --version
安装adb环境指令：sudo apt install -y android-tools-adb
